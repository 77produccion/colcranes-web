# COLCRANES web

Sitio corporativo de Colcranes, construido con Astro.

## Requisitos

- Node.js `>=22.22.0`
- npm

## Desarrollo

```sh
npm install
npm run dev
```

## Producción

```sh
npm run build
npm run preview
```

Las imágenes publicadas se encuentran en `public/images`. El archivo resultante del build se genera en `dist/` y no se versiona.
